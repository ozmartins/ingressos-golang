# web

Terminal retrô (monitor de fósforo) da plataforma de ingressos, feito com Vite + React + TypeScript.
Os comandos (`help`, `clear`, `echo`, `date`, `whoami`, `about`) são simulados no navegador.

Pré-requisito: Node.js 22.12+ e npm.

```
npm install        # instala as dependências
npm run dev        # servidor de desenvolvimento (http://localhost:5173)
npm test           # testes da lógica de comandos, histórico e linhas
npm run build      # checagem de tipos + build de produção em dist/
npm run preview    # serve o build de dist/
```
